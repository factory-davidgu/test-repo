# Nova Calculator

A slick, glassmorphic calculator built with plain HTML, CSS, and JavaScript — no dependencies.

## Features

- Glassmorphism UI with an animated ambient background glow
- Full keyboard support (digits, `+ - * /`, `Enter`/`=`, `Backspace`, `Esc`, `%`)
- Chained operations, percentages, sign toggling, and decimals
- Responsive layout for mobile and desktop
- Graceful handling of divide-by-zero and overflow (`Error`)

## Run it

Just open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
